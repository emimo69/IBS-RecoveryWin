# Analisi boot UEFI
Identificare ESP, file EFI, BCD e partizione Windows senza scritture. Valutare UEFI/Legacy, Secure Boot e BitLocker. Non modificare BootOrder/BootNext, EFI o BCD in diagnosi. Proporre `bcdboot` solo indicando lettere di unità verificate nella sessione WinRE, backup previsto ed esatta partizione target; eseguire solo dopo consenso.
