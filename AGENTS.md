# IBS-RecoveryWin 1.0

Regole obbligatorie per Codex:
- Lavora solo in /opt/ibs-recoverywin-1.0.
- Non modificare i precedenti progetti IBS.
- Non eliminare funzionalità funzionanti.
- Non modificare dischi fisici.
- Non compilare ISO senza autorizzazione.
- Dopo ogni modifica completa esegui commit e push su GitHub.
- Verifica che il push remoto sia riuscito.
- Se il push fallisce, fermati.
- Esegui verifiche reali prima di dichiarare una funzione operativa.

Prima fase:
Debian Trixie amd64, XFCE italiano.
Utente admin con password admin.
Login automatico e SSH attivo.
TeamViewer automatico, ID/password sul desktop.
Non implementare ancora NAS, USB o QEMU.
